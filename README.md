# 🎙️ PodCast Hub

## Sobre o projeto

O **PodCast Hub** é um sistema web desenvolvido como parte de um Projeto Integrador. A plataforma tem como objetivo facilitar o gerenciamento de podcasts e episódios, permitindo cadastrar, consultar, editar, excluir e organizar conteúdos de forma simples e prática.

## 🎯 Objetivo

Desenvolver uma plataforma que centralize o gerenciamento de podcasts e seus episódios, facilitando a organização das informações e a busca por conteúdos.


### Link do protótipo de alta fidelidade feito pelo Figma: https://www.figma.com/design/8GM4r7R4IYAWkyFNmir6Jc/Untitled?node-id=0-1&t=2ATVi8cKm3tRK0yd-1


## 💻 Tecnologias utilizadas

- **HTML5:** estrutura das páginas.
- **CSS3:** estilização e aparência do sistema.
- **PHP:** desenvolvimento do backend.
- **MySQL:** armazenamento e gerenciamento dos dados.
- **Figma:** criação do protótipo e planejamento visual.

## ⚙️ Funcionalidades

- Cadastro e gerenciamento de podcasts.
- Cadastro e gerenciamento de episódios.
- Edição e exclusão de informações.
- Consulta de podcasts e episódios.
- Pesquisa e filtros por título e categoria.
- Organização dos episódios relacionados a cada podcast.
- Sistema de autenticação de usuários.

## 🗄️ Banco de dados

O sistema utiliza o MySQL para armazenar as informações.

A estrutura relaciona podcasts e episódios, permitindo que um podcast possua vários episódios.
